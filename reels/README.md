### 10월 8일 23:55 · 서민금융 100만원, 다 갚으면 이자 절반 돌려받아요

[⬇️ 이미지 받기](https://raw.githubusercontent.com/koongkwanp-source/koan-cards/main/reels/20261008-145311-66acd463/summary.jpg)

```

불법사금융예방대출은 연체가 없으면 소득이 없어도 최초 100만원까지 빌릴 수 있어요.

```
